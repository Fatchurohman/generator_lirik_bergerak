📖 Panduan Penggunaan

  1. Pilih Lagu: Klik tombol pilih file untuk memasukkan audio lagu (MP3, WAV, atau M4A) dari HP atau laptop.
  2. Masukkan Lirik: Tempel (paste) lirik polos di kotak teks. Pastikan 1 kalimat = 1 baris (baris kosong otomatis dibuang).
  3. Mulai Sesi: Klik Mulai Sesi Tandai Lirik. Lagu otomatis diputar dari detik ke-0.
  4. Tandai Waktu: Dengarkan lagu. Tepat saat baris lirik yang tampil di layar mulai dinyanyikan, tekan Spasi (laptop) atau ketuk tombol hijau TANDAI WAKTU (HP).
  5. Salin ke GitHub: Setelah selesai, klik Salin Hasil Synced Lyrics lalu tempel ke file lirik atau katalog JSON di repositori GitHub kamu.
💡 Tips Cepat:
• Salah pencet? Klik Undo untuk membatalkan baris terakhir, geser mundur sedikit pemutar audio, lalu tandai ulang.
• Butuh jeda? Tekan Pause pada pemutar audio kapan saja, lalu Play lagi tanpa mengulang dari awal.
Contoh format hasil:
0:(Intro - Musik mulai) 12:Baris pertama lirik lagu 18:Baris kedua lirik lagu
